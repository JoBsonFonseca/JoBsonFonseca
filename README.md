# 💻 Sobre mim

Sou Analista de Qualidade de Software (QA), formado em **Análise e
Desenvolvimento de Sistemas** e certificado **ISTQB CTFL**.

Tenho experiência com testes manuais e automatizados para aplicações Web
e APIs, atuando desde o levantamento dos requisitos até a automação dos
cenários críticos, garantindo qualidade durante todo o ciclo de
desenvolvimento.

Possuo experiência com automação utilizando **Playwright** e
**Cypress**, testes de APIs REST, consultas SQL, versionamento com Git,
integração contínua e acompanhamento de demandas através do Azure
DevOps.

Meu foco é desenvolver soluções de automação escaláveis, reutilizáveis e
de fácil manutenção, contribuindo para entregas rápidas e confiáveis.
